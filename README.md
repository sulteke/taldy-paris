# Taldy-Paris — сайт ресторана

Маркетинговый сайт семейного ресторана **Taldy-Paris** (восточная и европейская
кухня, г. Талдыкорган). Построен на Next.js (App Router) + TypeScript + Tailwind
CSS. Контент статический (SSG) — без бэкенда, CMS и базы данных. Конверсия —
через WhatsApp.

## Стек

- **Next.js 14** (App Router), статическая генерация (SSG) всех страниц
- **TypeScript**, строгий режим
- **Tailwind CSS** с дизайн-токенами бренда (teal / gold / cream)
- **next/font** — Playfair Display + Inter с кириллическим сабсетом, `display: swap`
- **lucide-react** — иконки

## Ключевые возможности

- **Три языка — ҚАЗ / РУС / ENG.** Переключатель стоит **рядом с логотипом**
  Taldy-Paris (виден и на мобильном), выбор сохраняется в `localStorage`.
  **Язык по умолчанию — казахский** (`src/i18n/config.ts`, `DEFAULT_LANG`).
  Словарь — `src/i18n/dictionary.ts`, провайдер — `src/i18n/provider.tsx`.
  *Названия блюд остаются на русском* (дословно из печатного меню — перевод 200+
  кулинарных названий привёл бы к неточностям). Переводятся навигация, заголовки,
  кнопки, формы и названия категорий меню.
- **Бронирование столика (booking-first).** Глобальная форма-шторка
  (`src/components/BookingDrawer.tsx`, состояние — `src/booking/provider.tsx`)
  открывается кнопкой «Брондау» из шапки, героя, CTA и нижней панели —
  **гостю не нужно заходить в корзину, чтобы забронировать**. Поля: имя, телефон,
  дата, время, количество гостей, пожелания. Отправка собирает сообщение в WhatsApp.
- **Предзаказ (корзина) как опция брони.** На «Меню» у каждого блюда есть «＋».
  Плавающая корзина (`src/components/CartWidget.tsx`) с количеством и **суммой**
  (парсинг цены — `src/cart/provider.tsx`, `localStorage`) открывает ту же шторку;
  чекбокс «Себеттегі тапсырысымды қосу» прикрепляет заказ + итог (+12%) к брони.
- **Авто-карусели.** Фирменные блюда на главной и **«Хиты продаж» внизу меню**
  (`src/components/SignatureCarousel.tsx`, данные — `topSales` в `src/data/menu.ts`):
  бесконечная прокрутка, пауза при наведении, стоп при `prefers-reduced-motion`.
- **Карта реального адреса.** `src/components/MapEmbed.tsx` — встроенная карта
  Google (keyless `output=embed`) по точному адресу + кнопки «Открыть в 2ГИС»
  (приоритет для Казахстана) и «Google Maps». Точные GPS-координаты / firm-id 2ГИС
  можно подставить для более точного пина.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # продакшн-сборка (SSG)
npm run start    # запуск собранной версии
npm run lint
```

## Структура

```
src/
  app/                 # 6 страниц: /, /menu, /about, /gallery, /banquet, /contact
    layout.tsx         # Header + Footer, шрифты, мета, JSON-LD Restaurant
    sitemap.ts         # /sitemap.xml
    robots.ts          # /robots.txt
    icon.svg           # фавикон (плейсхолдер)
  components/          # типизированные переиспользуемые компоненты
  data/
    menu.ts            # ВЕРБАТИМ-меню (источник правды для /menu)
    site.ts            # факты о бизнесе, ссылки WhatsApp, навигация
    amenities.tsx      # удобства интерьера
    gallery.ts         # элементы галереи
```

## Контент — источник правды

- **Меню** (`src/data/menu.ts`) перенесено **дословно** из печатного меню
  (`files/taldy-paris-menu-content.md`): названия и цены не изменялись, не
  переводились и не округлялись.
- Факты о бизнесе (адрес, телефон, Instagram, обслуживание 12%, приветствие)
  заданы в `src/data/site.ts` и используются как есть.

## ⚠️ Перед запуском — заменить плейсхолдеры

Реальных ассетов в исходных материалах не было. Ниже — всё, что помечено как
плейсхолдер и требует реальных данных от клиента.

### 1. Логотип
- `src/components/Logo.tsx` — временный вордмарк (Playfair Display + line-art
  дерево). Нужен профессиональный векторный логотип (перерисовка круглого
  teal-знака с деревом).
- `src/app/icon.svg` — временный фавикон. Заменить на финальный набор иконок
  (16/32/180/512px + maskable).

### 2. Фотографии (нет ни одной в исходниках)
Все изображения сейчас — брендовые градиентные плейсхолдеры
(`src/components/Placeholder.tsx`), отрисованные в финальных пропорциях (нет CLS).
Нужно подготовить и подставить реальные фото (`next/image` рекомендуется,
WebP/AVIF, `srcset`, lazy-load):
- 2–3 hero-кадра (интерьер / фирменное блюдо) — Home, About, Banquet
- 15–20 фото блюд (Новинки, Салаты, Стейки, Рыба, Банкет)
- 6–10 фото интерьера (VIP-кабины, детская, намазхана, зал, летник)
- 2–4 lifestyle-кадра (гости)
- Галерея (`src/data/gallery.ts`) и Instagram-лента (`InstagramStrip.tsx`)

### 3. OG-картинка
- В `src/app/layout.tsx` указан `/og-image.png` — добавить файл **1200×630** в
  `public/` (для красивых ссылок в мессенджерах/соцсетях).

### 4. Часы работы — `{{HOURS}}`
- Нет в исходниках. Сейчас отображается «уточняйте по телефону». Указать реальные
  часы в `src/data/site.ts` (`hours`) и раскомментировать вывод в Footer/Contact.
- После этого добавить `openingHoursSpecification` в JSON-LD (`layout.tsx`).

### 5. GPS-координаты — `{{LAT}}`, `{{LNG}}`
- Нет в исходниках. Карта (`MapEmbed.tsx`) пока ведёт на поиск Google Maps по
  адресу. Указать координаты в `site.geo`, добавить `geo` в JSON-LD и заменить
  блок на реальный `<iframe>`-эмбед при желании.

### 6. Домен / URL сайта
- `site.siteUrl` = `https://taldy-paris.kz` (плейсхолдер). Используется в
  `metadataBase`, canonical, `sitemap.xml`, `robots.txt`. Заменить на реальный
  домен.

### 7. E-mail
- В исходниках нет — намеренно не добавлен. Контакт идёт через
  телефон / WhatsApp / Instagram. Добавить при необходимости.

## Что реализовано по брифу

- 6 страниц, общий Header (sticky, мобильное меню) + Footer
- Меню: липкие вкладки категорий с горизонтальным скроллом, scroll-spy, поиск,
  пунктирные лидеры цен, заметка «Обслуживание 12%», мобильная WhatsApp-панель
- Галерея: фильтры, masonry, доступный лайтбокс (клавиатура / Esc / стрелки)
- Банкет: featured-сет, карточки сетов с прокинутым в WhatsApp составом
- Контакты: форма, собирающая готовое сообщение в `wa.me` (без бэкенда)
- SEO: уникальные title/description (RU), JSON-LD `Restaurant`, OG/Twitter,
  `sitemap.xml`, `robots.txt`, canonical
- Доступность: `lang="ru"`, семантические лендмарки, skip-link, видимый фокус,
  `aria-label` на иконочных кнопках, `prefers-reduced-motion`
- Производительность: статическая генерация, лёгкий JS, шрифты с сабсетом

> Примечание: меню содержит цены в тенге; перед публикацией стоит сверить
> актуальность цен с рестораном.
